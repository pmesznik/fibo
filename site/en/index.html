FIBO

FIBO is a photo manager and editor for Windows, inspired by Picasa 3. It organizes photos by year, tag and place on a globe, fixes them in one click and finds duplicates. Everything happens on your own computer.

Download the latest version

Windows 10 and 11, 64-bit

All versions · Source on GitHub

The installer is not code-signed yet, so Windows may warn you on first launch. See “Installation” for details.

What FIBO does

Library by year

Photos laid out by the date they were taken, with year and month headings and a grid that keeps original proportions.

Tags, ratings, favorites

Label photos with tags and stars, filter and search. No account, no cloud.

Editor with effects

Quick fixes, cropping, light curves and over 30 effects. Your original always stays safe.

Collages

Grid, mosaic, photo pile or contact sheet from selected photos, ready to print.

Globe of photos

Pins where your photos were taken. Click a pin to see the photos from that place.

Duplicates

Finds identical and similar photos, suggests the best one and moves the rest to the Recycle Bin.

Documentation

Installation

Requirements: Windows 10 or 11 (64-bit). WebView2 ships with Windows 11 and recent Windows 10. If it is missing, the installer downloads it, so an internet connection is needed in that case.

  1. Download FIBO_<version>_x64-setup.exe from the home page or from the GitHub releases.
  2. Run it. It installs for your user account only and needs no administrator rights.
  3. FIBO appears in the Start menu.
Windows warns or blocks the installer? The installer is not yet signed with a certificate, so:
  • SmartScreen (“Windows protected your PC”): click More info, then Run anyway.
  • Smart App Control can block an unsigned program entirely. Then you can wait for a signed version or turn the feature off in Windows Security. Note that once turned off it cannot be turned back on without resetting Windows, so that is your call.

Uninstall: Settings → Apps → FIBO → Uninstall. Your library and thumbnails stay in the data folder (see “Data and privacy”), so reinstalling loses nothing.

Getting started

  1. Click + in the top right corner and choose a folder with photos. FIBO scans it with all subfolders.
  2. Photos appear while scanning. Large libraries are scanned in batches, so you can see progress.
  3. Double-click a photo to open it full screen with the editor.

Supported formats: JPG, PNG, WebP, GIF, BMP and TIFF. RAW, HEIC and video files are not supported yet.

Screen layout. The main screen is kept clean: the menu button (☰) top left, the + button top right and a floating view bar at the top (Library, Albums, Favorites, People, Map). Tools live in the menu on the left: search, quick actions, filters, tags, folders and appearance.

Library and albums

  • Grouping by date. Photos are ordered by the date taken (from EXIF data, or the file date if missing). Headings show years or months, and the “Year” chips scroll to a chosen year. Switch it in the menu → Appearance → Grouping.
  • Grid. By default, rows of equal height where every photo keeps its own proportions. You can switch to equal 4:3 tiles and change the thumbnail size in the menu → Appearance.
  • Albums are folders with photos grouped by year, newest first. An album’s year is the year of its newest photo.
  • Favorites shows photos marked with a heart.
  • Selecting many photos: Ctrl + click adds a photo, Shift + click selects a range. “Select many” mode in the menu replaces Ctrl.
  • Slideshow starts from the menu or in the viewer (space).

Search and filters

In the menu, type part of a file name, camera or tag into Search. Under Filters:

  • Rating and sorting: minimum number of stars; sort newest first, oldest first or by name (date grouping is off when sorting by name).
  • Tags: selecting several tags shows photos that have all of them.
  • Folders: limits the library to one folder.

Active filters appear as chips above the grid; clicking a chip removes the filter.

Tags, ratings and favorites

  • Tags: select one or more photos and click the tag icon on the bottom bar. Type a name and press Enter, or pick an existing tag. Tags are stored in lowercase (up to 40 characters). With several photos, a partly applied tag shows “2/5”. The same tag editor is in the viewer’s Info tab.
  • Removing a tag from all photos: menu → Tags → pick the tag → “Remove tag”. The app asks for confirmation, and the photos themselves stay.
  • Ratings: 1 to 5 stars (keys 1–5, 0 clears).
  • Favorites: the heart or the F key.

Metadata in files (XMP)

Tags, ratings and favorites are stored not only in the FIBO library but also in XMP files next to your photos (for example photo.jpg.xmp). They do not vanish with the database, and other programs (digiKam, Lightroom, darktable) can read them. The photos themselves are not modified.

  • Automatic saving is on by default. Turn it off in the menu → Metadata in files, which also has a Save everything to XMP files button.
  • XMP files from other programs are left untouched: FIBO recognises them by the missing FIBO marker and skips them.
  • Reading: when adding photos, FIBO picks up the tags and ratings they already have: from Windows Explorer (“Tags” and “Rating”), from XMP and IPTC in JPEG files (the way Picasa stored them) and from .xmp files next to the photos. For photos already in the library use Load tags and ratings from files. Reading only adds: it never overwrites ratings or removes tags.
  • A tag the photo already has is not added a second time.

Your own albums

Albums in Albums → My albums do not depend on folders: they are your own collections, and one photo can be in many albums. Files stay where they are.

  • New album: the New album button, or right-click selected photos → Add to album… → New album….
  • Opening an album shows its photos in the library. Right-click → Remove from this album takes photos out of the album (not off the disk).
  • Each album has rename and delete buttons. Deleting an album does not delete photos. Album names are unique (case does not matter).

Watched folders

A folder added with Add folder is watched from then on. FIBO checks it after launch, when you return to the window (at most once per 30 seconds) and every 5 minutes:

  • new photos are added automatically, together with tags and ratings stored in the file (a notification appears),
  • photos whose files vanished from the disk disappear from the library. If a whole folder is unavailable (for example an unplugged drive), nothing is removed,
  • unchanged files are skipped, so checking a large library is fast.

The list of watched folders is in the menu → Watched folders. Clicking a folder (after confirmation) stops watching it, and its photos stay in the library. Check for new photos now checks immediately.

File operations

Right-click a photo or a selection. The menu acts on all selected photos:

  • Rating (stars), favorite, Tags…, Add to album…, Collage (from two photos), Select all.
  • Rename file… (one photo): the extension stays and the XMP file is renamed with the photo. FIBO rejects names with characters Windows does not allow (\ / : * ? " < > |), reserved names (CON, NUL, COM1…) and never overwrites an existing file.
  • Move to folder… and Copy to folder…: nothing is overwritten, and when a name is taken FIBO appends _1, _2. The XMP file goes with the photo. Moving across drives copies, checks the size and only then removes the source.
  • Import from card (menu, quick actions): pick a memory card or folder, then a library folder. FIBO copies photos into YYYY/YYYY-MM-DD subfolders by capture date (from the file, or the file date when missing) and adds them to the library. Photos already imported are skipped, nothing is overwritten, and the card is left untouched.
  • Rename selected… gives many photos names from a template: photo date, your own name and a running number, e.g. 2024-07-01_Holiday_001.jpg. You see a preview first. XMP files follow the photos and existing files are never overwritten.
  • Set location… lets you mark where the selected photos were taken: click the place on the map or type coordinates. The photos then show up on the globe in the Map tab. The location is stored only in the FIBO library (photo files are not changed) and a manual location takes precedence over the GPS in the file.
  • Export resized… saves copies of the selected photos to a folder you pick: 1024, 1600, 2048 px or original size, as JPEG at the quality you choose. Copies carry no EXIF data, so they do not reveal location, and originals are untouched.
  • Remove from library (files stay)… hides photos in FIBO and leaves the files on disk untouched. Bring them back with Restore hidden photos in the menu (Folders section) or by adding the folder again.
  • Move to Recycle Bin… asks for confirmation and moves the files to the Windows Recycle Bin, from where you can restore them. For 20 or more photos, and for all photos of a folder, you must type USUŃ. FIBO only deletes photos it knows about, never a whole folder.

Photo viewer

Double-click a photo (or press Enter) to open it full screen. The top bar has the name, rating, favorite, undo and redo, slideshow, zoom, compare with original and full screen; the bottom has a thumbnail strip. Arrows at the edges switch photos.

Zooming: the mouse wheel zooms at the cursor, dragging pans the image, and double-click toggles between fit-to-window and 100% (keys +, - and Z). Before and after: hold the compare button or the B key to see the untouched original.

The wand button (or the E key) opens the edit panel. The Info tab shows name, folder, dimensions, size, date taken, camera and tags.

Photo editor

The edit panel has four tabs. Changes show live, and you can undo without limits while editing (Ctrl + Z and Ctrl + Y).

  • Basics: I’m Feeling Lucky, Auto Contrast, Auto Color and Fill Light in one click; rotate and flip; straighten; red-eye removal (click the center of the eye); cropping at 1:1, 4:3, 3:2, 16:9 and more, with zoom and pan.
  • Tuning: fill light, highlights, shadows, brightness, contrast, gamma, color temperature, saturation and sharpen. Double-click a slider to reset it.
  • Text on photo (Effects tab): type a caption and add it, then set size, horizontal and vertical position, colour and bold. You can add several captions. The text is burned into the saved photo (saving as a copy leaves the original untouched) and can be undone before saving.
  • Effects (over 30, some with a strength slider): black and white, sepia, warmify, film grain, glow, Orton, soft focus, vignette, Lomo, Polaroid, HDR, heat map, night vision, posterize, pixelate, pencil sketch, comic, neon, border and more. They stack in the order you pick them.

Saving

  • Save changes overwrites the file. Before that FIBO copies the original to a .originals folder next to the photo (only the first time).
  • Save as copy creates a new file with _edit appended and leaves the original untouched.
  • Restore original undoes an overwrite from the copy in .originals.
  • GIF, BMP and TIFF are always saved as a JPG copy. Saving removes EXIF data from the file, but the date taken, camera and GPS position stay in FIBO’s database.

Collages

Select at least two photos (up to 30) and choose Collage from the bottom bar or the menu.

  • Layouts: Grid, Mosaic (rows that fill the canvas), Photo pile (scattered, in white frames; “Shuffle” rolls a new arrangement) and Contact sheet (with file names).
  • Canvas: 16:9, 4:3, 3:2, 1:1, 3:4 or 9:16, four backgrounds, spacing and corner rounding.
  • Saving: a new 2800 px wide JPG, kolaz_YYYYMMDD_HHMMSS.jpg, in the first photo’s folder. Originals are never changed.

Map

The Map tab shows a globe with pins where your photos were taken. Photos from one place share a pin with a count, and nearby pins form a cluster. Click a cluster to zoom in, or a pin to open a panel with thumbnails. Click a thumbnail to open the viewer.

The map shows where it is day and where it is night right now, with a smooth twilight band. At the bottom are a clock, a time slider (±12 hours), a Now button and a day animation button that sweeps a whole day in a few seconds. The Sun's position is computed on your computer.

  • Positions come from the GPS data in your photos (EXIF). Photos without GPS do not appear, and the counter in the corner shows how many there are.
  • Photos added before map support have no stored coordinates: choose Load locations from photos in the Map tab or Refresh photo data in the menu.
  • The map downloads tiles from the free OpenFreeMap service, so it needs internet. The rest of the app works offline.

People (face recognition)

The People tab groups photos by person. The feature is off by default: you turn it on with Turn on face recognition after reading the privacy notice. Analysis runs in the background (you can pause and resume it) and new photos are added automatically.

  • Nothing leaves your computer. Faces are detected and compared locally (YuNet and SFace models shipped inside the installer, nothing is downloaded while the app runs). The module has no network code, and tests verify it.
  • Face vectors are encrypted with your Windows account key (DPAPI). A copied FIBO database does not reveal them.
  • Names stay in the FIBO database and never go into photo files or XMP.
  • For each person you can name, pick a cover (the face shown in the list), merge (when one person ended up in two groups): drag one person onto another and click Confirm or ignore them. Click a person to see their photos.
  • Delete face data removes people, vectors and face crops and turns the feature off. Your photos are untouched.

Duplicates

Menu → Duplicates. Pick a level and click Find duplicates:

  • Identical files: same content (same size and checksum). Fastest and safe.
  • Very similar: the same shot after resizing, recompression or a small edit.
  • Similar: also bursts of shots. Different photos can show up, so check before deleting.

Results are groups of photos with dimensions, size, folder and date. The photo with the crown Best (highest resolution, then largest file) stays, and the others are pre-selected for removal. At least one photo always stays in each group. Move to Recycle Bin asks for confirmation and moves files to the Windows Recycle Bin, from where you can restore them.

Data and privacy

  • Your photos never leave your computer. FIBO has no accounts and sends no photos or statistics. The only internet use is downloading map tiles when you open the Map tab (and possibly downloading WebView2 during installation).
  • The library (index, ratings, tags, coordinates) is the library.db database in %APPDATA%\pl.local.menedzerzdjec, and thumbnails are in its thumbs subfolder. Back it up by copying that folder. The folder has that name for technical reasons and does not change across updates.
  • Copies of originals after editing are in .originals folders next to your photos, and tags, ratings and favorites are also in .xmp files next to the photos (this can be turned off in the menu).
  • Uninstalling does not delete your photos or your library.

Updates

Starting with version 0.2.0, FIBO checks GitHub for a newer version by itself:

  • The check runs automatically once a day (shortly after launch, and when the app stays open for long it checks hourly whether a day has passed; silently when offline) and on demand: menu → Check for updates. A manual check always shows its result in a dialog: a new version, you are up to date, or an error.
  • When a new version exists, FIBO asks: Download and install, Later (it will ask again the next day) or Skip this version. The release notes are shown in the dialog.
  • If you agree, FIBO downloads the installer with a progress bar, installs it and restarts. Save any open photo edits first.
  • Updates are signed with the author’s key, and the app installs only updates with a valid signature. Your library, ratings and tags are untouched.
  • The version number is shown in the menu header. Version 0.1.0 must be updated by hand once, because it does not have this feature yet.

FAQ

Windows blocks the installer or the program.

The program is not signed yet. See “Installation”: SmartScreen can be bypassed with “Run anyway”, while Smart App Control may require turning it off or waiting for a signed version.

The map is empty or shows an error.

The map needs internet. If you are online but there are no pins, choose “Load locations from photos”: photos added earlier have no stored coordinates. Photos without GPS (such as screenshots) do not appear on the map.

Portrait photos have the wrong proportions in the grid.

Click “Refresh photo data” in the menu. It re-reads the dimensions taking rotation into account.

Does editing damage my originals?

No. When overwriting, FIBO first copies the original to the .originals folder, and “Save as copy” does not touch the file at all. “Restore original” undoes an overwrite.

Can I get deleted duplicates back?

Yes. Files go to the Windows Recycle Bin, from where you can restore them.

Where is my library?

In %APPDATA%\pl.local.menedzerzdjec. See “Data and privacy”.

Building from source

Requirements: Node.js 22, Rust (stable) and Visual Studio Build Tools with C++.

git clone https://github.com/pmesznik/fibo.git
cd fibo/app
npm ci
npx tauri dev      # development mode
npx tauri build    # installer in src-tauri/target/release/bundle/nsis

New version: node scripts/bump-version.mjs 0.2.0 sets the version number in three files. After pushing the tag v0.2.0, GitHub Actions builds the installer and publishes a release with the file FIBO_0.2.0_x64-setup.exe. This site fetches the latest release number by itself.
